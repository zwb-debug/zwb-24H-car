# 02 硬件与接线

> 目标：照着这张表接线，一次上电成功。所有引脚与 `firmware/2024_H.syscfg` 一致；
> 改引脚只需要在 SysConfig 里改，C 代码用的是生成宏，不用动。

## 3. 分模块接线

### 3.1 TB6612 + 电机

| TB6612 端子 | 接到 | 备注 |
|---|---|---|
| VM | 电池 +（7.4V，经开关） | 并 1000µF + 0.1µF 到 GND |
| VCC | 5V | 逻辑电源 |
| GND | 公共地 | 与 MCU、传感器共地 |
| PWMA | PA12 | 左 |
| AIN1 | PB0 | 左 |
| AIN2 | PB1 | 左 |
| AO1 / AO2 | 左电机 M+ / M- | 转向反了就对调这两根 |
| PWMB | PA13 | 右 |
| BIN1 | PB4 | 右 |
| BIN2 | PB5 | 右 |
| BO1 / BO2 | 右电机 M+ / M- | |
| STBY | PB6 | 高电平使能 |

### 3.2 编码器

| 编码器线 | 接到 |
|---|---|
| VCC | 5V（多数 N20 编码器 5V 供电，A/B 输出 3.3–5V） |
| GND | 公共地 |
| A 相 | 左 PA16 / 右 PA24 |
| B 相 | 左 PA17 / 右 PA25 |

- 代码用**四倍频**：`ENC_PPR=13`、`ENC_MULT=4`、`GEAR_RATIO=30` → 1560 counts/轮转；
- 若你的编码器是 11 线或 1:50 减速比，改 `board.h` 对应宏即可，`COUNTS_PER_CM` 会自动重算。

### 3.3 8 路灰度 ⚠️

| 灰度板 | 接到 |
|---|---|
| VCC | 5V |
| GND | 公共地 |
| OUT0（最左） | PB8 |
| OUT1…OUT6 | PB9…PB14 |
| OUT7（最右） | PB15 |

**电平警告**：5V 供电的数字灰度，输出高电平是 5V，直接进 MSPM0（3.3V）会通过 ESD 二极管灌电流，轻则读数异常，重则烧脚。务必：

- 买 **3.3V 供电** 的灰度模块；或
- 每路串 1kΩ 电阻 + 3.3V 钳位二极管（BAT54S 接 3.3V）；或
- 用 74LVC245 做 8 路电平转换。

**方向约定**：人站在车尾、面向车头，CH0 在最左、CH7 在最右。装反了会把"左偏"当成"右偏"，车会直接冲出赛道。用 `K4` 翻到灰度柱状图页，用手指依次挡探头核对。

### 3.4 JY61P 陀螺仪

| 模块 | 接到 |
|---|---|
| VCC | 5V |
| GND | 公共地 |
| TX | PA9（UART1 RX） |
| RX | PA8（可不接） |

模块配置（用维特上位机，一次性）：

1. 波特率 **115200**；
2. 回传速率 **100Hz 或 200Hz**；
3. 只勾选 **角度（0x53）** 帧，其它帧全部关掉（帧率都给角度）；
4. 安装：箭头朝车头，水平放置，用泡棉胶固定；
5. 上电后静置 3s 再发车（内部姿态解算收敛）。

> 若你的模块出厂是 9600，请改模块为 115200，或把 `board.h` 的 `IMU_BAUD` 改成 9600（同时改 syscfg 里 UART1 波特率）。

### 3.5 OLED

| OLED | 接到 |
|---|---|
| VCC | 3.3V 或 5V（看模块丝印） |
| GND | 公共地 |
| SCL | PB2 |
| SDA | PB3 |

- 地址 0x3C（若模块是 0x3D，改 `bsp_oled.c` 的 `OLED_ADDR`）；
- 模块一般自带 4.7k 上拉；若没有，外接 4.7k 到 3.3V。

### 3.6 按键、蜂鸣器、LED

```
按键（4 个相同）：
   GPIO ──┬── 按键 ── GND
          └── （内部上拉，无需外接）

蜂鸣器（有源）：
   PB7 ── 1kΩ ── S8050 基极
   S8050 发射极 ── GND
   S8050 集电极 ── 蜂鸣器负极
   蜂鸣器正极 ── 5V
   （蜂鸣器两端并 1N4148，负极接 5V）

LED：
   PA15 ── 1kΩ ── LED 正极 ── GND
```

## 4. 电源与布线

### 4.1 电源树

```
2S LiPo 7.4V ── 3A 保险丝 ── 船型开关 ──┬── TB6612 VM
                                        └── mini560 5V ──┬── TB6612 VCC
                                                          ├── 灰度 5V
                                                          ├── 陀螺仪 5V
                                                          ├── OLED
                                                          └── 地猛星 5V 引脚
```

- 地猛星可以用 USB-C 供电调试，但**比赛时必须由车载 5V 供电**（USB 线拔掉）；
- 所有 GND 单点汇合到电池负极，电机大电流不要流过灰度地线；
- 电机线双绞，远离灰度排线；灰度排线尽量短（<15cm）；
- 电池用魔术贴+扎带固定，插头朝车尾，方便开关。

### 4.2 上电顺序

1. 电池插头断开，开关 OFF；
2. 万用表测 5V 降压输出，调到他 5.0V；
3. 只给主板上电（USB 或 5V），确认 OLED 亮、串口有数据；
4. 再插电机电源，开关 ON；
5. 手拿住车（轮子悬空），串口发 `m300,300`，确认转向。

## 5. 装配步骤

1. **底盘**：装两轮电机、万向轮；轮子用胶水/紧定螺钉固定在电机轴上（原版开源方案就是轮子打滑，查了一通宵）。
2. **电机驱动**：TB6612 用铜柱固定在底盘，VM/GND 先接电机电源，逻辑侧留排针。
3. **主控**：地猛星用铜柱架高，USB-C 朝车尾，方便插线；芯片面朝上（裁判要能看到 TI 丝印）。
4. **灰度条**：用 2mm 亚克力/洞洞板做横梁，固定在前端，离地 8–12mm，探头间距 15mm；排线从车体一侧走。
5. **陀螺仪**：底盘几何中心，箭头朝前，泡棉胶减振。
6. **OLED**：装在车尾上方，方便看；I2C 线双绞。
7. **按键**：车尾一排 4 个，标注 K1–K4。
8. **蜂鸣器/LED**：朝上/朝后，裁判能听到看到。
9. **电池**：底盘中部偏后，扎带固定。
10. **配重**：若前轮（万向轮）易离地，在车头加 20–30g 配重。

## 6. 装配后检查清单

- [ ] 长 ≤25cm、宽 ≤15cm、高 ≤15cm（含探头、排线、OLED）
- [ ] 两轮转动方向一致（发 `m300,300` 都向前）
- [ ] 手推前进，遥测 `vL`、`vR` 都为正
- [ ] 灰度 CH0 在最左；白纸全 0，黑线对应位为 1
- [ ] 陀螺仪左转 yaw 增大；静置 10s 漂移 <0.5°
- [ ] OLED 三页都能显示，按键都能触发
- [ ] 蜂鸣器能响、两个 LED 能亮
- [ ] 电池满电 8.4V；5V 输出 5.0±0.1V
- [ ] 所有接插件有防松（热熔胶/扎带）
- [ ] 车头芯片丝印可见，无摄像头

## 7. 常见硬件坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 上电不启动、串口无输出 | PA18 被拉高进入 BSL | 确保 PA18 上电为低；不要用 PA18 做按键 |
| 灰度某一路恒为 1 | 该路探头/比较器坏，或引脚被板载占用 | 换一路引脚（SysConfig 改）；用柱状图页定位 |
| 电机一转，OLED 花屏/复位 | 电机电源干扰，5V 跌落 | VM 加 1000µF；5V 加 100µF；电机线远离 I2C |
| 编码器计数乱跳 | 上拉不足/线太长/电机干扰 | 内部上拉已开；缩短线；加 0.1µF 到 GND |
| 陀螺仪数据乱码 | 波特率不对/接了 5V TX 到 3.3V RX | 统一 115200；确认模块 TX 是 3.3V 电平 |
| 轮子转但车不走 | 轮轴打滑 | 胶水/紧定螺钉固定轮子 |
| 一加速就偏 | 两轮摩擦力/负载不一致 | 轮速 PI 已闭环；检查轮胎是否蹭底盘 |
