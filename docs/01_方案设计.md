## 1. 题目解读

### 1.1 场地与路径

题图几何（单位 cm，左下角为原点）：

```
        y=120 ┌──────────────────────────────────────┐
              │        A(60,100)      B(160,100)     │
              │      ╱                        ╲      │
              │    ╱   R40 左弧          R40 右弧  ╲   │
              │   │                                │  │
              │    ╲                              ╱   │
              │      ╲                        ╱      │
              │        D(60,20)        C(160,20)     │
        y=0   └──────────────────────────────────────┘
             x=0                                    x=220
```

- 场地 220×120cm，两条 **R=40cm** 的半圆弧，线宽 1.8cm；
- 顶点：A(60,100)、B(160,100)、C(160,20)、D(60,20)；
- **AB、CD、AC、BD 都没有画线**，场内除两段圆弧外无任何标记（连 A/B/C/D 字母都不许有）。

这一点决定了整个方案：**直线段没有任何视觉反馈**，只能靠陀螺仪保持航向、编码器计量里程；圆弧段才有黑线可循。

### 1.2 四道题的动作序列

| 题 | 路径 | 关键动作 | 限时 | 分值 |
|---|---|---|---|---|
| 1 | A→B | 直线 100cm，到 B 停车，声光提示 | 15s | 20 |
| 2 | A→B→(右弧)→C→D→(右弧)→A | 整圈，每过一个顶点声光提示 | 30s | 20 |
| 3 | A→C→(左弧)→B→D→(右弧)→A | 8 字一圈，顶点转向 38.66° | 40s | 30 |
| 4 | 第 3 题路线 ×4 圈 | 连续 4 圈，圈间在 A 点转向 | 越短越好 | 30 |

### 1.3 硬性约束（违反即不测试）

1. **只能前进，不得后退**——不能用车轮反转做原地转；
2. 必须 **TI MSPM0** 系列 MCU 控制整车，主板要露出芯片；
3. **不得安装摄像头**；
4. 尺寸 ≤25cm(长)×15cm(宽)×15cm(高)，含所有传感器；
5. 轮式，不得履带、不得麦轮；
6. 车载电池，测试中途不得换电池；
7. 起跑/停车/经过 A/B/C/D 时，**地面投影必须覆盖顶点**；在圆弧上行驶时投影不得脱离圆弧；
8. 不得借助场外任何装置/标记/遥控。

> "只能前进"是本方案和网上多数开源方案最大的不同点：他们用 `SpeedL=-30, SpeedR=30` 原地打转，严格说违规；我们用**内轮停转、外轮正转**的方式绕内轮转向，任何时刻两个轮子的速度都 ≥0。

## 2. 总体方案

### 2.1 系统框图

```
                  ┌──────────────────────────────┐
   8路数字灰度 ──►│                              │──► TB6612 ──► 左电机(编码器)
    JY61P 陀螺仪 ─►│   地猛星 MSPM0G3507 32MHz    │──► TB6612 ──► 右电机(编码器)
   4 个按键    ──►│   (实际 32MHz 内部时钟)      │
   OLED(I2C)   ◄──│                              │──► 蜂鸣器 + 2×LED
   CH340(UART0)◄──►│                              │
                  └──────────────────────────────┘
```

- **感知**：8 路数字灰度（横向偏差）+ JY61P（航向）+ 双编码器（速度/里程）；
- **决策**：200Hz 状态机，按"里程"切段，按"航向/偏差"闭环；
- **执行**：TB6612 双路 20kHz PWM，轮速 PI 内环。

### 2.2 为什么是"2WD + 万向轮"

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 4WD 滑移转向 | 抓地力大、能爬小坎 | 转向时四轮互相"别劲"，打滑严重；编码器里程在弯道失真 5–15%；原地转要反转车轮（违规） | 不选 |
| 2WD + 万向轮 | 真正的差速运动学，`ω=(vR-vL)/W` 成立；里程准；转向不打滑 | 抓地力较小，加速不能太猛 | **选它** |
| 阿克曼转向 | 转向几何精确 | 需要舵机+连杆，车宽难压到 15cm，倒车/原地调整困难 | 不选 |

### 2.3 为什么是"灰度 + 陀螺仪 + 编码器"

摄像头被禁；激光雷达/超声波无法识别 1.8cm 黑线；因此横向偏差只能来自灰度。航向只能来自陀螺仪（地磁在场馆内受钢筋/灯光干扰，不可靠）。纵向里程只能来自编码器（单纯陀螺仪二次积分会发散）。

三者互补：

- 直线：**陀螺仪**保方向，**编码器**量 100cm；
- 圆弧：**灰度**修横向，**陀螺仪切线**做前馈/兜底，**编码器**量 180°；
- 顶点：**编码器**里程到点即判定，不依赖"扫到/扫不到线"。

### 2.4 与原版开源方案的关键差异

网上流传最广的方案（2024 H 题开源）用"白地/圆弧区切换"作为节点判据，第 4 题在第三圈半因为进弧没压到线而失败。本方案：

| 问题 | 原方案 | 本方案 |
|---|---|---|
| 节点判定 | 灰度全 0 ↔ 有线 的跳变 | 里程计到点，灰度只做辅助确认 |
| 丢线 | 逻辑卡死/节点后移 | 按陀螺仪切线+里程继续走完已知圆弧 |
| 第 4 题多圈 | 依赖每圈都完美压线 | 每圈在 A 点用绝对航向重新对准，误差不累积 |
| 转向 | 反转车轮原地转（违规） | 内轮 0、外轮正转，绕内轮转（合规） |
| 调参 | 改代码重烧 | 串口在线改 PID，OLED 实时看偏差 |

## 3. 机械设计

### 3.1 尺寸分配（总 ≤25×15×15cm）

```
        车头（灰度条）
   ┌──────────────────────┐  ↑ 8cm 探头到轮轴
   │   ○ ○ ○ ○ ○ ○ ○ ○    │
   │  ┌────────────────┐  │
   │  │  地猛星 + OLED  │  │  宽 13cm（含轮）
   │  │  TB6612  电池   │  │
   │  └────────────────┘  │
   │   ●轮          轮●    │  轴距 ≈ 13cm
   └──────────────────────┘
   总长 ≈ 20cm（含探头支架与尾部配重）
```

- 轮距（左右轮中心距）实测填入 `CAR_W_CM`，默认 12.0；
- 灰度条到轮轴距离实测填入 `SENSOR_AHEAD_CM`，默认 8.0；
- 灰度探头离地 8–12mm，8 个探头间距 15mm，总跨度 105mm；黑线宽 18mm，保证至少一路压线；
- 陀螺仪用 3M 泡棉双面胶固定在底盘中心、箭头朝车头，远离电机；
- 电池尽量低、居中偏后，重心在两轮之间稍靠后，减少加速时前轮（万向轮）离地；
- 所有传感器/排线不得超出 25×15×15cm 包围盒——赛前用纸箱做个"检具"试一下。

### 3.2 投影覆盖顶点的校核

题目要求停车/过点时**车的投影覆盖顶点**。车长 20cm，只要停车位置误差 <8cm、航向误差 <10°，矩形投影必然盖住顶点。本方案里程误差目标 <1cm/100cm，转向误差 <1.5°，余量很大。

## 4. 硬件设计

### 4.1 电源树

```
2S LiPo 7.4V ──┬── 开关 ── TB6612 VM（电机）
               │            │
               └── 5V/3A DC-DC ──┬── TB6612 VCC（逻辑）
                                 ├── 灰度/陀螺仪/OLED
                                 └── 地猛星 5V 引脚（板载 3.3V LDO 给 MCU）
```

- 电机与逻辑**同地**，但电机电源线单独走、远离灰度信号线；
- TB6612 VM 并 1000µF 电解 + 0.1µF 陶瓷，抑制电机换向尖峰；
- 灰度/陀螺仪供电若与电机共用 5V，务必在模块端再加 100µF；
- 电池电压从 8.4V 掉到 7.0V 时，同样占空比下转速会掉 15%，所以**每次测试前充满电**，或者用电压补偿（本固件未做，属于可加分项）。

### 4.2 电机驱动

TB6612 真值表（每路）：

| IN1 | IN2 | PWM | 输出 |
|---|---|---|---|
| 1 | 0 | PWM | 正转 |
| 0 | 1 | PWM | 反转 |
| 0 | 0 | × | 滑行 |
| 1 | 1 | × | 短路刹车 |

本工程用 **1 路 PWM + 2 路方向**，20kHz（32MHz/1600），高于人耳可闻范围，电机不啸叫。

### 4.3 电平与接口

- TB6612 逻辑高阈值 2.0V，3.3V GPIO 可直接驱动；
- JY61P 模块 TX 为 3.3V TTL，直接进 PA9；
- 灰度模块（5V 供电）输出经比较器为 5V 推挽，**不能直接进 3.3V GPIO**！两种做法：
  1. 买 3.3V 供电的灰度模块；或
  2. 每路串 1kΩ + 3.3V 肖特基钳位，或加 74LVC245 电平转换。
  **这是最容易烧板子的一处，务必确认。**
- OLED 模块自带 3.3V LDO，VCC 接 5V 或 3.3V 均可（按模块丝印）。

### 4.4 引脚分配原则

- 避开板载占用：PA10/PA11（CH340）、PA14（LED）、PA18（BSL 按键）、PA19/PA20（SWD）；
- 编码器用**同一端口**（GPIOA），一个中断服务函数读 4 个脚，抖动小；
- 灰度用连续 8 个 PB 脚，一次 `readPins` 读完，避免分两次读造成错位；
- PWM 用 TIMG0 的 CCP0/CCP1（PA12/PA13），不与其它外设冲突；
- 全部引脚都在 `2024_H.syscfg` 里，改引脚不影响 C 代码。

## 5. 控制算法

### 5.1 运动学

两轮差速：

```
v   = (vL + vR)/2          （车体线速度）
ω   = (vR - vL)/W          （车体角速度，逆时针为正）
vL  = v - ωW/2
vR  = v + ωW/2
```

### 5.2 轮速内环（200Hz）

```
duty = Kff·v_ref + Kp·(v_ref - v_meas) + Ki·∫(v_ref - v_meas)dt
```

- `Kff = 14`（占空比 per cm/s）：前馈承担主要输出，PI 只修负载/电压变化；
- 积分限幅 ±400，输出 0…1600；
- 静摩擦补偿：`v_ref>1` 时最小占空比 95；
- 占空比变化率限制 90/5ms，保护齿轮；
- 实测速度一阶低通（α=0.45），抑制编码器量化噪声。

### 5.3 直线航向环

```
eψ = wrap(ψ_ref - ψ)
ω  = Kp·eψ + Ki·∫eψ + Kd·deψ/dt
vL = v - ωW/2,  vR = v + ωW/2
```

- `Kp=0.020 rad/s per deg`，`Ki=0.0015`，`Kd=0.0025`；
- 陀螺仪零漂由 Ki 吸收（但积分限幅 ±60，避免起步"甩头"）；
- 前馈：直线段不需要，靠 PID 即可。

**为什么不用纯 P**：JY61P 的 yaw 有 0.5–1° 的静态偏差，纯 P 会留下固定横向偏差；Ki 在 5s 内可把它压到 0.2° 以内。

### 5.4 圆弧循迹环

```
e   = 灰度加权位置（mm，右正左负）
ω_ff = v/R · dir                      ← 曲率前馈（关键）
ω   = ω_ff - (Kp·e + Ki∫e + Kd·ė) + Kh·(ψ_t - ψ)
ψ_t = ψ_start + dir·(s/R)·(180/π)     ← 切线参考（已知几何）
```

- **曲率前馈是圆弧能跟住的关键**：R=40cm、v=31cm/s 时，车体需要 0.775rad/s 的角速度；只靠 PD，需要 7.7cm 的偏差才能凑出这个角速度，早已超出探头量程；
- `Kp=0.010 rad/s per mm`：偏差 10mm → 0.1 rad/s（约 5.7°/s），只负责修正；
- `Kd=0.0006`：抑制 8 路数字量的阶跃抖动；灰度位置先做一阶低通（α=0.45）再微分；
- `Kh=2×Kp_h=0.04`：陀螺仪航向阻尼，防止"画龙"；
- 丢线时 `e` 置 0，`ω_ff` 和切线参考仍在，车会沿理论圆弧走完 180°；
- 偏差 >25mm 自动降速，避免甩出。

### 5.5 转向（38.66° 与圈间转向）

- 目标航向是**绝对航向**（场地坐标），不是"转固定角度"，所以每一圈都能把上一段的误差清零；
- 内轮 0、外轮 `vout = clamp(1.1·|eψ|, 3, 26)`；
- 绕内轮转：`ω = vout/W`，38.66° 约 0.4s，车体中心前移 `(W/2)·Δψ ≈ 4cm`；
- `|eψ|<1.2°` 判定到位，进入下一段；下一段的航向环会修掉残余 1°。

### 5.6 速度规划

每段按梯形/三角形规划：

```
v_allow = sqrt(v_end² + 2·a_dec·(L - s))
v_ref   = min(v_cruise, v_allow)
```

- 直线末端若是转向，`v_end = 16cm/s`（带一点动量进弯，避免停死）；
- 最后一段 `v_end = 0`，在离终点 2–3cm 时速度已 <3cm/s，直接抱死；
- 加速度限幅 160cm/s²，减速度 180cm/s²（受轮胎抓地力限制，太大编码器会打滑）。

### 5.7 为什么外环 200Hz 就够

- 车体机械时间常数 ≈ 0.1–0.2s（质量/轮胎），200Hz 采样有 20–40 个点/时间常数；
- 轮速内环 200Hz，外环 200Hz，内外环带宽比约 5–10，不会互相激发；
- OLED/串口都在主循环，不占用控制节拍。

### 5.8 控制律仿真校验

在写死参数之前，先用 `tools/control_sim.py`（两轮差速 + 一阶速度响应 + 前伸 8cm 探头）把 `control.c` 的控制律跑了一遍，确认符号与增益：

**圆弧（R=40cm，v=31cm/s）**

| 初始横向偏差 | 初始航向偏差 | 1s 后最大偏差 | 稳态偏差 | 稳态航向误差 |
|---|---|---|---|---|
| +5.0cm | 0° | 1.31cm | +0.17cm | +0.34° |
| +5.0cm | +5° | 0.98cm | +0.17cm | +0.34° |
| +3.0cm | 0° | 0.94cm | +0.17cm | +0.34° |
| 0 | +5° | 0.17cm | +0.17cm | +0.34° |
| -3.0cm | 0° | 0.19cm | +0.17cm | +0.34° |

**直线（v=32cm/s，走 100cm）**

| 初始航向偏差 | 终点横向偏差 | 终点航向 |
|---|---|---|
| +1° | +0.48cm | -0.02° |
| +2° | +0.96cm | -0.04° |
| +3° | +1.44cm | -0.06° |
| +5° | +2.40cm | -0.09° |

结论：

- 曲率前馈 `v/R` 是圆弧能跟住的关键——没有它，PD 需要 7.7cm 的稳态偏差才能凑出 0.775rad/s 的角速度，早已超出探头量程；
- 前伸探头会带来约 0.17cm 的"切内"稳态偏差，可忽略；
- 初始 5cm 的入弧偏差能在 1s 内收敛，说明进弧速度 31cm/s、探头 8cm 的配置是合理的；
- 直线 3° 摆放误差只造成 1.4cm 终点偏差，所以第 1 题的关键确实是摆放。

> 仿真是**理想运动学 + 一阶速度环**，不含轮胎打滑、地面不平、陀螺仪噪声；实车必须重新标定，但它能排除符号错误和数量级错误。完整输出见 `docs/control_sim.txt`，可改 `tools/control_sim.py` 里的增益复现。

## 7. 误差分析（报告"理论分析"可直接用）

### 7.1 直线段横向误差

设起跑航向误差 ε₀，陀螺仪随机漂移 ε_d，里程 L：

```
y_L ≈ L·tan(ε₀) + L·ε_d + L·δ_scale·sin(ε₀)
```

- ε₀=1°、L=100cm → 1.75cm；
- ε_d=0.5°/min，跑 5s → 0.04°，可忽略；
- 编码器尺度误差 1% → 1cm（只影响纵向停车点）；
- 合计 <3cm，远小于车宽 15cm 的一半，B 点必被覆盖。

**结论**：第 1 题的关键不是控制，而是**起跑摆放**。用激光笔/直角尺对准，比调 PID 有效。

### 7.2 转向角度误差

转向闭环精度 ±1.2°，转完后走 128cm 对角线，横向误差 `128×tan(1.2°)=2.7cm`。圆弧捕获窗口 ±5cm（8 路×15mm），仍有 2cm 余量。

### 7.3 圆弧段

灰度量化误差 ±7.5mm（相邻探头间距的一半），PD 后稳态误差 <10mm；车宽 15cm，投影覆盖 1.8cm 黑线绰绰有余。

### 7.4 第 4 题累积误差

每圈在 A 点做"绝对航向转向"，把上一圈的航向误差清零；每段起点在顶点重置 `s=0`，把里程误差清零。**误差不跨圈累积**，这是能稳定跑 4 圈的根本原因。

### 7.5 主要误差源排序

| 误差源 | 量级 | 对策 |
|---|---|---|
| 起跑摆放角度 | 1–3° | 激光笔/挡板对准 |
| 轮径标定 | 1–3% | 跑 200cm 反算 `WHEEL_D_CM` |
| 陀螺仪零漂 | 0.5–2°/min | 每圈绝对航向修正；赛前预热 1min |
| 灰度漏线 | 偶发 | 探头间距 ≤15mm；丢线走理论圆弧 |
| 轮胎打滑 | 加速/转向时 | 加速度限幅；轮轴用胶水固定（原方案的坑） |
| 电池压降 | 末端 10–15% | 满电；前馈+PI 可部分补偿 |

## 8. 关键难点与对策

| 难点 | 现象 | 本方案对策 |
|---|---|---|
| 直线没线 | 第 1 题一跑就歪 | 陀螺仪航向 PID + 编码器定距；起跑对准 |
| 进弧抓不到线 | 车斜着冲过 B 点 | 进弧前减速到 16cm/s；灰度条前伸 8cm 提前看到线；丢线按切线走 |
| 线卡在两探头之间 | 全 0 误判白地 | 探头间距 15mm < 线宽 18mm；丢线 200ms 内用航向，不切状态 |
| 转向过冲 | 8 字越跑越偏 | 内轮 0 的绕轮转 + 绝对航向 + 1.2° 死区 + 下一段航向环收残差 |
| 第 4 题圈间累积 | 第 3 圈出界 | 每圈在 A 点重置航向/里程；不依赖灰度跳变计数 |
| 陀螺仪漂移 | 后两圈方向偏 | 绝对航向每圈修正；预算够就换 HWT101 |
| 只能前进 | 原地转被判违规 | 内轮 0、外轮正转；代码里 `vref` 下限钳 0 |
